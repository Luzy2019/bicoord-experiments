可以，直接把这句包进 `nohup bash -c '...'`：

```bash
mkdir -p logs && nohup bash -c 'bash train_2unet_base.sh stack_bowls demo_clean 50 100 14 0 160 0.25 -2.0 && shutdown -h now' > logs/2unet_base_$(date +%m%d_%H%M).log 2>&1 &
```

这个版本是：**训练成功结束后才关机**。

如果你想无论成功还是失败都关机，用：

```bash
mkdir -p logs && nohup bash -c 'bash train_2unet_base.sh stack_bowls demo_clean 50 100 14 0 160 0.25 -2.0; shutdown -h now' > logs/2unet_base_$(date +%m%d_%H%M).log 2>&1 &
```

推荐用第一个 `&& shutdown -h now`。查看日志：

```bash
tail -f logs/2unet_base_*.log
```
